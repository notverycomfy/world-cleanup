# Contributing to World Cleanup

Thanks for helping improve World Cleanup. Search existing issues before opening a new one, and keep each report focused on one problem or suggestion.

## Bug reports

Include the Minecraft and loader versions, whether the problem occurred on a dedicated server or local world, the relevant configuration, and steps to reproduce it. Attach the latest log or crash report when relevant.

## Code changes

1. Create a branch from the supported-version branch affected by the change.
2. Keep changes focused and preserve existing configuration behavior.
3. Run `./gradlew build` before submitting a pull request.
4. Explain the server or player-facing behavior and how it was tested.

Do not include generated build output, game saves, logs, or redistributed third-party assets.
